# Generator marks

The chip in the expert directory masks these to one ink, so a mark whose
detail is a colour rather than a hole flattens into a blob. Most of these came
from the old marketing site's own icon set and survive that; Jekyll, Hugo and
Eleventy did not, and are the single-path glyphs from
[Simple Icons](https://simpleicons.org) 13.21.0 instead, which are drawn for
monochrome use and are CC0.
